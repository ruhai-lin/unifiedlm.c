# 逐 token 差距：輸在哪些 token

**問題**：統一 block 跟 Transformer 的差距落在哪些 token 上？

**簡短回答**：15M 贏的近九成是照抄前文；42M 輸的全是窗口裡沒出現過的新 token。

## 怎麼做的

- 128 個長 1,024 的驗證窗口（每個模型同一批），逐 token 算 NLL，跟同規模的 Transformer 相減（`scripts/fineweb/tokgap.py`）。
- 每個要預測的 token x_{t+1} 按窗口裡它之前出現過什麼分三類：**二元組重複**（(x_t, x_{t+1}) 這一對之前出現過，照抄前文就猜得到）、**見過**（x_{t+1} 出現過，但不是接在 x_t 後面）、**新**（窗口裡還沒出現過）。
- 另外按它在第一個訓練 shard 的頻率排名分四組，再把三類各按位置分成 0–64、64–256、256–1,024。
- 窗口比正式評測少（128 對 2,048），所以總差距跟正式數字略有出入：42M U-Delta-rawFFN+λlr1000 在這裡 +0.005，正式評測 +0.009。

## 結論

- **15M 贏的主要是照抄前文**：U-Delta-rawFFN+λlr1000 贏 Transformer 0.135，其中 88.9% 來自二元組重複的 token（占 19.9%）：Transformer 2.017 對 1.416。15M 的 Transformer 還不太會照抄；42M 的 Transformer 在同一類降到 1.116，跟統一 block 打平（1.111）。
- **42M 剩下的差距全在窗口裡沒出現過的新 token**（占 44.1%）：U-Delta-rawFFN+λlr1000 +0.020、U-Delta-rawFFN +0.027；二元組重複和見過的 token 反而略贏（-0.005、-0.008）。新 token 在前 64 個位置不輸（-0.006），64 之後輸 0.022–0.025。
- **15M 也輸在 64 之後的新 token**（+0.022、+0.022），只是被照抄上的大優勢蓋過去。所以這是統一 block 兩個規模共同的弱點。
- **按頻率**：42M 輸在最常見的前 100 個 token（占 43.3%，+0.014），1K 以後的少見 token 略贏；15M 每一組都贏，越少見贏越多（10K 以後 -0.540）。
- **15M 新 token 的差距靠 FFN 讀未歸一化的位址補上，不是靠記憶設計**：64–256 的新 token，U-Delta +0.169，保留慢記憶的 U-Delta+slow +0.155、U-Delta-diverseλ +0.141、U-Delta-spreadλ +0.157，記憶短的 U-Delta-λlr1000 +0.114；U-Delta-λlr1000 再讓 FFN 讀未歸一化的位址（= U-Delta-rawFFN+λlr1000）降到 +0.022，UD2 -0.010。含 attention 的 U-Delta+attn +0.108，對 0–64 和 64–256 補的量差不多。
- **讀出端的修改多贏在照抄、見過的 token 和 64 以後的新 token**：對 Transformer，UD2 -0.148，UD2-gate -0.156，UD2-gate-norm -0.182，UD2-gate-q32 -0.177；UD2-scale -0.145 跟 UD2 一樣。UD2-gate-norm 多出來的一半以上在見過的 token（-0.118，UD2-gate -0.079）。
- **讀位址修正補最多的是位置 64–256 的新 token**：UD2-gate-q32 -0.029，UD2-gate-norm -0.022，UD2-gate -0.010。符合“共享的位址只能找相似、不能找相關”的推測，但不改位址的 UD2-gate-norm 也補了一大半，還不能說都是位址的功勞。兩個一起的 UD2-gate-norm-q32 -0.039，每一類都領先（全部 -0.197）；修正加到秩 128 的 UD2-gate-q128 只剩 -0.006，每一類都比秩 32 差。
- **旋轉相對位置的進步在新 token**：UD2-gate-norm-q32-rope 對 Transformer 全部 -0.202（UD2-gate-norm-q32 -0.197）；新 token -0.057 對 -0.040，位置 256–1,024 的新 token -0.052 對 -0.032；照抄反而略差（-0.619 對 -0.637）。多 head 的 UD2-gate-norm-h4q8 照抄最好（-0.651），新 token 變弱（-0.032）；除以記憶量的 UD2-gate-mass-q32 見過的 token 最差（-0.093）。
- **42M 的 UD2-gate-norm-q32-rope 每一類都贏 Transformer**：全部 -0.045，照抄 -0.038、見過的 token -0.065、新 token -0.031；贏的 52.2% 來自見過的 token，新 token 30.7%。U-Delta-rawFFN+λlr1000 42M 輸在 64 以後的新 token（+0.025、+0.022），這個反過來贏（-0.021、-0.033）；越少見的 token 贏越多（頻率前 100 -0.012，1K–10K -0.085）。各 1 個 seed。
- 推測（還沒驗證）：統一 block 的記憶按位址取回存過的值，照抄已經追平或更好；輸的是拿整段前文來猜還沒出現過的詞，這需要按內容綜合整段上下文，是 attention 擅長的。

## 注意

- 各 1 個 seed、128 個窗口。
- 分類只看同一個 1,024 窗口裡的前文。
- 差距的分攤只說明輸在哪裡，不說明原因。
